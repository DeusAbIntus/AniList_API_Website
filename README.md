# AniList_API_Website
Capstone Project to Practice communicating with an API (In this case AniList)
I have created a simple Webapp that communicated with the public Anilist API. The API uses the GraphQL framework to receive queries and send the requested data.
I have incorporated node, express and Axios to create the server code. The WebApp is just designed to retrieve Anime suggestion based on the filtered Genres selected by the user.

Quick Start Guide:
1. Git clone the repo.
2. npm i
3. nodemon/node index.js
